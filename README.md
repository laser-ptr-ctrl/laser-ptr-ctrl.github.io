# laser-ptr-ctrl.github.io

The public Astro marketing site for **Laser Pointer Control**.

Realtime 3D pan-and-tilt control across web, Flutter, native desktop, Arduino, and Raspberry Pi.

## Development

Use Node.js 22.22.1 or newer.

```sh
npm ci
npm run dev
npm run build
```

Astro writes the production site to `dist/`. The committed GitHub Actions workflow builds pull requests and deploys the default branch to GitHub Pages.
